# Контракт модуля `app/src/quote.ts`

> Згенеровано промптом `prompts/document-module.md`. Джерело істини — код і
> тести `app/src/quote.test.ts`; кожна гарантія посилається на тест.

## `estimateTotalCents(input): number`

**Гарантує**
- Повертає ціле невід'ємне число центів (округлення half-up). Доказ: тести
  «рахує суму без знижки» (50000), «застосовує знижку» (45000).
- `discountPercent = 100` → `0`. Доказ: тест «знижка 100% дає 0».
- Підтримує дробові `hours`. Доказ: тест «підтримує дробові години» (1.5 → 7500).

**НЕ гарантує**
- Точність для дробових `hours`, де проміжний добуток виходить за межі безпечних
  цілих або дає IEEE-похибку. Валідуємо лише скінченність результату — тесту на
  цю межу немає (свідома межа контракту, див. коментар у коді).

**Кидає `QuoteInputError`**
- `hours`/`rateCents` не скінченні або від'ємні; `discountPercent` поза 0..100
  або `NaN`; результат не скінченний. Доказ: параметризований тест «кидає
  QuoteInputError» (7 випадків, включно з `NaN`, `Infinity`, `discountPercent=150`).

## `splitInstallments(totalCents, parts): number[]`

**Гарантує**
- `sum(result) === totalCents` — головний інваріант. Доказ: параметризований тест
  «сума часток дорівнює цілому» (8 випадків, зокрема 100/3, 100000/7, 5/2).
- `result.length === parts`; усі елементи цілі; `max - min <= 1`. Доказ: той самий тест.
- Розкидає залишок на **перші** платежі. Доказ: тест «розкидає залишок» (100/3 → [34,33,33]).
- Працює для від'ємних сум (повернення). Доказ: тест «працює для від'ємних сум» (−100/3 → [−34,−33,−33]).

**НЕ гарантує**
- Рівність усіх часток, якщо сума не ділиться націло (це неможливо в цілих центах).

**Кидає `QuoteInputError`**
- `totalCents` не безпечне ціле (напр. `2**54`, `100.5`); `parts` не ціле або
  поза `1..MAX_INSTALLMENTS` (1200). Доказ: параметризований тест «кидає
  QuoteInputError» (6 випадків).

## `formatMoney(cents): string`

**Гарантує**
- Для будь-якого цілого `cents` — рядок `[-]$<тисячі>.<2 цифри>`. Доказ: тести
  «форматує центи» ($1,234.50), «нуль і дрібні» ($0.00/$0.05/$0.99), «від'ємні»
  (−$1,234.50).

**НЕ гарантує**
- Нічого для нецілих значень — вони відхиляються (див. нижче).

**Кидає `QuoteInputError`**
- `cents` не ціле (`1.5`, `NaN`, `Infinity`). Доказ: параметризований тест
  «кидає QuoteInputError» (3 випадки).

## Відкриті питання

- Округлення `estimateTotalCents` для «злих» дробових годин (напр. `1.005 * 100 =
  100.4999…` в IEEE 754) не покрите тестом. Якщо бізнес вимагає гарантованого
  half-up для таких входів — потрібна арифметика на цілих/decimal, а не
  `Math.round` над float. Наразі — свідомо поза контрактом.
