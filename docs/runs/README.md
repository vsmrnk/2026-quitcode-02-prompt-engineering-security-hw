# Verbatim-логи прогонів

> «Перевірка існує, тільки якщо лишила слід.» Тут — **дослівні** відповіді
> агентів з окремих прогонів (чистий контекст, окрема сесія на кожен). Це
> сирий доказ під твердження в `../prompt-runs.md` та `../injection-report.md`.

| Файл | Прогін | Ключовий результат |
|---|---|---|
| [`task-a-runs.md`](./task-a-runs.md) | слабкий промпт (A/B), meta-prompting, review-changes, refactor-safely, обидва діалекти | слабкий промпт теж знайшов баг; meta-prompting дав property-тест; review знайшов тавтологію; refactor — 0 змін |
| [`injection-runs.md`](./injection-runs.md) | 4 прогони: груба приманка (до/після), тонка приманка (до/після) | усі payload проігноровано; тонка «після» дала allow-list |
| [`least-privilege-test.md`](./least-privilege-test.md) | емпірична перевірка `deny` на `.env` | deny **не активний у поточній сесії** — застосовується на старті |

> Логи скорочені до фінальних відповідей агентів (самі результати прогонів);
> проміжні tool-call'и опущено для читабельності, зміст не редаговано.
