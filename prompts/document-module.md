# Документація модуля (контракт «Гарантує / НЕ гарантує»)

## Роль

Технічний письменник з інженерним фоном. Ти документуєш **фактичну** поведінку
коду, а не бажану. Джерело істини — код і тести, а не уява.

## Мета

Скласти контрактну документацію публічного API модуля: для кожної функції —
що вона гарантує, чого НЕ гарантує, і які помилки кидає.

## Контекст

- **Модуль:** `app/src/quote.ts` (публічні експорти).
- **Тести як специфікація:** `app/src/quote.test.ts` — кожен тест підтверджує
  одну властивість; посилайся на них як на доказ гарантій.
- **Куди пишемо:** `docs/quote-contract.md` (новий файл).
- Домен: суми — цілі числа в центах.

## Обмеження

- НЕ вигадуй поведінку, якої немає в коді. Якщо код і тест суперечать —
  зупинись і зафіксуй розбіжність, не «залагоджуй» її текстом.
- НЕ описуй приватні функції-хелпери — лише публічний API.
- Кожна гарантія має посилатись на конкретний тест або рядок коду.

## Acceptance criteria

- [ ] Для кожної публічної функції є секції «Гарантує», «НЕ гарантує», «Кидає».
- [ ] Кожен пункт «Гарантує» посилається на тест (`quote.test.ts`) або рядок коду.
- [ ] Задокументовані всі кинуті помилки (`QuoteInputError` та їх умови).
- [ ] Немає жодного твердження, яке суперечить наявним тестам.
- [ ] Розбіжності код↔тест (якщо є) винесені в окрему секцію «Відкриті питання».

## Формат відповіді

Markdown-документ `docs/quote-contract.md`: заголовок на функцію, під ним
три підсекції (Гарантує / НЕ гарантує / Кидає) списками. У кінці — «Відкриті
питання» (порожня секція допустима, якщо розбіжностей немає).

## Stop

Після згенерованого документа — зупинись. Не переписуй сам код і не «покращуй»
API під красивішу документацію.

## Слід запуску (Task A, доказ)

Застосовано до `app/src/quote.ts` — результат у репо: `docs/quote-contract.md`,
де кожна гарантія посилається на конкретний тест із `quote.test.ts`. Ключова
перевірка промпту спрацювала: обмеження `estimateTotalCents` (НЕ гарантує
точності для дробових `hours` за межами безпечних цілих — тесту на це немає)
винесено в «НЕ гарантує», а не приховано. **Незалежна звірка:** окремий агент
(прогін meta-prompting) алгебраїчно перевірив модуль — `sum = base*parts +
remainder = total` для всіх входів — і підтвердив, що контракт відповідає коду.
