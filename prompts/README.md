# Prompt cookbook

Бібліотека перевірених промптів команди. Кожен промпт — окремий файл за
структурою [`_template.md`](./_template.md), перевірений на реальній задачі
(ціль за замовчуванням — `app/`).

## Індекс

| Промпт | Категорія | Що робить | Перевірено на |
|---|---|---|---|
| [`add-tests.md`](./add-tests.md) | тести | Розширює покриття й знаходить дефекти | `app/src/quote.ts` (знайшов ваду) |
| [`review-changes.md`](./review-changes.md) | рев'ю | Рев'ю робочого дерева до коміту (з untracked) | діф Task A |
| [`document-module.md`](./document-module.md) | документація | Контракт «Гарантує / НЕ гарантує» зі звіркою з тестами | `quote.ts` → `docs/quote-contract.md` |
| [`refactor-safely.md`](./refactor-safely.md) | рефакторинг | Структурні зміни без зміни поведінки | `quote.ts` |
| [`debug-failing-test.md`](./debug-failing-test.md) | дебаг | Локалізує причину падіння тесту | інваріант суми |
| [`draft-integration-spec.md`](./draft-integration-spec.md) | задача агенції · **2 діалекти** | Чернетка тех-специфікації з санітизованого брифу | `docs/sanitized-brief.md` |
| [`draft-pr-description.md`](./draft-pr-description.md) | dev-воркфлоу | Опис PR з фактичного дифу гілки | діф `ws02/vsmrnk` |
| [`review-pr.md`](./review-pr.md) | _(приклад-планка з репо, не рахується)_ | Рев'ю дифу гілки перед мержем | `app/src/quote.ts` |

**7 власних промптів** (не рахуючи `review-pr.md` і `_template.md`), покриття:
тести · рев'ю · документація · рефакторинг · дебаг · задача агенції · dev-воркфлоу.
Промпт `draft-integration-spec.md` наведено у **двох діалектах** (markdown + XML).
Слід кожного запуску — у [`../docs/prompt-runs.md`](../docs/prompt-runs.md).

## Правила цієї бібліотеки

1. Один промпт — одна задача. Якщо в описі є «і ще», це два промпти.
2. Кожен промпт має **acceptance criteria**, які можна перевірити «так/ні».
3. Кожен промпт має **stop-правило** — де агент зупиняється.
4. Промпт без перевірки на реальній задачі у бібліотеку не потрапляє.
5. Змінюєте промпт — піднімайте `version` і пишіть, що саме змінилось.
